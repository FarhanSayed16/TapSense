## What we are installing

A small **measurement-only** kit on **3 washroom taps** (one floor):

- Inline **flow sensors** (YF-S201) to count liters  
- One **ESP32** Wi‑Fi board in a sealed box  
- Data goes to a private admin dashboard for the project team  

**This pilot does not:**

- Cut off or control water (no valves in this phase)  
- Track individual students (no ID cards / cameras / apps for users)  
- Change plumbing beyond a short inline sensor fitting

## Why

Campus taps often run with no feedback. This pilot measures real usage so we can later show liters at the tap and compare blocks — **with your permission at each step**.
